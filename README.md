\## Overview



This repository contains my Week 3 practical cybersecurity work.



The two required modules completed were:



\- W3-PM1 – Password Cracking with John the Ripper

\- W3-PM2 – Password Cracking with Networkwalks Tools



The project focused on understanding how password-protected PDF files can be tested using password recovery tools in an authorized lab environment.



\## W3-PM1 – John the Ripper



For this module, I used John the Ripper and the Johnny GUI on Windows.



The practical included:



\- Working with a password-protected PDF

\- Extracting the PDF hash

\- Saving the hash to a text file

\- Configuring Johnny to use John the Ripper

\- Loading the PDF hash

\- Running the password attack

\- Recovering the password

\- Confirming the recovered password by opening the PDF



Evidence is stored under:



`PM1-JTR/Screenshots`



\## W3-PM2 – Networkwalks Tools



For this module, I used the Networkwalks Hash Calculator and Password Cracker.



The practical included:



\- Uploading the protected PDF to the Hash Calculator

\- Extracting the PDF hash

\- Testing the built-in password list

\- Creating and using a custom wordlist after the first attempt failed

\- Recovering the password

\- Opening the PDF successfully



Evidence is stored under:



`PM2-Networkwalks-Tools/Screenshots`



\## Challenges



One challenge was configuring Johnny correctly so that it could locate the John the Ripper executable.



Another challenge was that the built-in Networkwalks password list did not recover the password. A custom wordlist was created and used successfully.
